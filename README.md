## 📌 About the Project

**India Live Weather** is a web-based weather application designed to provide an interactive weather experience with a modern interface, map visualization and weather monitoring features.

The application combines a responsive frontend, interactive maps and weather-related visualizations to make weather information easier to explore.

## ✨ Features

- 🌦️ Weather information interface
- 🇮🇳 India-focused weather experience
- 🗺️ Interactive map visualization
- 🌧️ Rain and radar visualization
- 📍 Location-based weather experience
- 📱 Responsive user interface
- 🎨 Modern UI design
- ⚡ Interactive frontend experience

## 🛠️ Technologies Used

- JavaScript

## 🚀 Getting Started

You can run this project locally on your computer.

### 1. Clone the Repository

```bash
git clone https://github.com/rahuldevnayak37-netizen/-All-India-Weather-App.git
```

### 2. Navigate to the Project Folder

```bash
cd -All-India-Weather-App
```

### 3. Open the Application

Open `index.html` in your browser.

You can also use the Live Server extension in Visual Studio Code for local development.
